# LG G Pad 8.3 Wi-Fi (V500)

LineageOS 21 ARMv7 product configuration for the APQ8064 tablet. The product uses the stock LineageOS setup wizard and Trebuchet. The display target is 1200 × 1920 with Mesa Freedreno on Adreno 320.

This is a hardware bring-up build. Physical touch setup has reached HOME. Display underruns, slow frames and launcher stability are under investigation. The current M6 tests use loop-backed images and a timed return to recovery.

Use the [V500 manifest and build instructions](https://github.com/Mitsch79/android_local_manifests_v500/tree/lineage-21.0).
